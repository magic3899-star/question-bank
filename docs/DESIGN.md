# 문제은행 — UI/디자인 가이드

대상: 출판사 담당 직원. 하루 종일 문제를 다루는 **업무용 도구**. 화려함보다 **차분함, 정확함, 빠른 작업**이 기준이다.
구현은 `src/app/renderer`. 이 문서의 토큰과 규칙을 벗어나는 임의 스타일을 만들지 않는다.

## 1. 원칙

1. **보이는 것이 곧 결과**: 화면 미리보기는 PDF 와 같은 렌더러(`render-html`)를 쓴다. 미리보기와 출력물이 다르면 안 된다.
2. **한 화면 한 목적**: 화면마다 주 행동 1개를 가장 눈에 띄게. 나머지는 보조.
3. **안전한 조작**: 삭제·덮어쓰기·가져오기 확정은 되돌릴 수 있게 하거나(실행 취소) 영향 범위를 먼저 보여준다. `confirm()` 대신 앱 안 대화상자.
4. **막히지 않는 오류**: 오류·경고는 "무엇이, 어디서, 어떻게 고치는지"를 한국어로. 빈 상태에는 다음 행동을 안내.
5. **밀도 있되 읽기 쉽게**: 목록은 촘촘하게, 문제 본문은 여유 있게.

## 2. 디자인 토큰 (CSS 변수, `src/app/renderer/styles/tokens.css`)

| 토큰 | 라이트 | 다크 |
|---|---|---|
| `--bg` | `#F6F7F9` | `#14161A` |
| `--surface` | `#FFFFFF` | `#1C1F25` |
| `--surface-2` | `#F0F2F5` | `#242830` |
| `--border` | `#E2E5EA` | `#2E333C` |
| `--text` | `#1A1D23` | `#E8EAEE` |
| `--text-muted` | `#5B6472` | `#98A1B0` |
| `--accent` | `#3B5BDB` | `#7C93F5` |
| `--accent-fg` | `#FFFFFF` | `#0F1220` |
| `--accent-soft` | `#E7ECFD` | `#262F55` |
| `--success` | `#247C47` | `#5CC98A` |
| `--warn` | `#9B5D00` | `#F0B24A` |
| `--danger` | `#D63A3A` | `#F27A7A` |

- 강조색은 `--accent` **하나만**. 상태색(성공/경고/위험)은 의미 전달에만 쓴다.
- 본문/배경 대비 WCAG AA(4.5:1) 이상. 색만으로 상태를 구분하지 않는다(아이콘·문구 병기).
- 강조 배경 위 글자는 `--accent-fg`를 사용한다. 상태색을 글자로 쓰는 경우 surface 대비 4.5:1 이상, 강조색 링크·아이콘은 3:1 이상이다. `styles/tokens.test.ts`가 라이트·수동 다크·시스템 다크를 검사한다. 라이트 성공·경고는 같은 초록·주황 계열에서 글자 대비를 높였다.

### 타이포
- UI: **Pretendard**(번들, OFL). 시험지 미리보기/출력: Windows 기본 **바탕**(본문) + **맑은 고딕**(제목) — Word 출력과 같은 글꼴이라 PDF·Word·미리보기가 일치한다(직원 PC 는 모두 한국어 Windows).
- 크기: 12 / 13(기본 UI) / 14 / 16 / 20 / 24. 줄간격 1.5(본문 1.7).
- 한국어 줄바꿈: `word-break: keep-all; overflow-wrap: anywhere;`
- 숫자는 `font-variant-numeric: tabular-nums` (표·카운트).

### 간격·모양
- 간격 스케일: 4 / 8 / 12 / 16 / 24 / 32. 반경: 6(입력·버튼) / 10(카드).
- 그림자는 최소(카드 `0 1px 2px rgba(0,0,0,.06)`), 모달만 크게. 구분은 가급적 `--border` 선.
- 아이콘: lucide-react, 선 두께 1.75, 16/20px.
- 모션: 120–180ms ease-out. `prefers-reduced-motion` 존중. 장식용 애니메이션 금지.

## 3. 레이아웃

- 창 최소 1100×700, 기본 1360×840. 고DPI 대응(이미지·아이콘 선명하게).
- 좌측 **사이드바**(폭 220, 접기 가능) + 상단 **페이지 헤더**(제목, 주 행동 버튼) + 본문. 필요 시 우측 **상세 패널**(폭 420, 리사이즈).
- 사이드바 메뉴: 홈 / 문제은행 / 가져오기 / 시험 만들기 / 출제 규칙 / 출제 이력 / 설정. 하단에 버전과 업데이트 상태.
- 선택 메뉴는 강조 배경으로 표시한다. 메뉴 접기 버튼은 하단 버전 위에 두고, 접힌 상태에서는 아이콘과 툴팁으로 표시한다.
- 키보드: 전 기능 Tab 이동 가능, 포커스 링 명확(2px `--accent`). 단축키: `Ctrl+K` 빠른 검색, `Ctrl+N` 새 문제, `Ctrl+G` 시험 만들기, `Ctrl+Z` 실행 취소.

## 4. 화면

### 4.1 홈
- 과목별 문제 수 카드, 최근 만든 시험 5건, **주의 필요 항목**(학습목표 없는 문제 N개 → 클릭 시 해당 목록), 업데이트 알림 배너.
- 빈 상태(문제 0개): "문제를 가져오거나 직접 추가해 보세요" + 큰 버튼 2개.

### 4.2 문제은행
- 좌: 필터 트리(과목 → 학습목표 계층, 각 노드 옆에 문제 수) + 검색창. 중: 문제 목록(번호, 본문 앞부분, 학습목표, 등급, 경고 아이콘). 우: 상세 패널(출력과 동일한 미리보기 + 해설 + 편집).
- 다중 선택 후 일괄 작업(태그, 삭제, 선지 고정 지정). 삭제는 실행 취소 토스트.
- 문제 편집기: 본문/선지/정답/해설/예문 영역별 편집, 서식(밑줄, 굵게), 이미지·표 삽입, 선지 드래그 정렬, 선지별 "위치 고정" 토글, 정답은 선지 옆 라디오/체크.

### 4.3 가져오기 (가장 중요한 화면)
1. 파일 끌어놓기 영역(여러 개 가능) → 분석 진행 표시.
2. **검수 표**: 상단 요약("문제 252개 · 경고 14 · 오류 3"). 필터(전체/경고/오류). 각 행: 원문 위치, 변환 결과 미리보기, 진단 배지.
   행을 펼치면 인라인 수정(학습목표 입력, 선지 수정) + "이 경고 무시".
3. 하단 고정 바: "정상 N개 저장" / "경고 포함 모두 저장"(영향 안내 대화상자) / 취소.
- 중복 의심(지문 동일)은 나란히 비교해서 "둘 다 유지/하나만"을 고르게 한다.

### 4.4 시험 만들기 (단계 마법사, 상단 스텝 표시)
1. 과목·규칙 선택 (규칙 요약 카드)  2. 옵션: 문제 순서 섞기 / 선지 섞기 / 정답 위치 균형 / 최근 N회 제외 / 시드(자동 또는 입력)
3. **사전 점검**: 슬롯별 후보 수와 필요 수를 막대로 표시. 부족하면 어느 슬롯이 몇 개 모자란지 안내(만들기 버튼 비활성).
4. 결과 미리보기: 회차 탭(1회~N회), 문제지/정답지/해설지 전환, 문제별 "다시 뽑기"(해당 문제만 같은 슬롯에서 교체).
5. 저장: 형식 체크(PDF/Word/Excel), 구성(문제·정답·해설, 합치기/나누기), 템플릿 선택, 폴더 선택 → 저장 후 "폴더 열기".

### 4.5 출제 규칙 편집기
- 슬롯 카드 목록(라벨, 개수, 필터). 각 슬롯에 **현재 후보 문제 수**를 실시간 표시.
- 제약 목록(종류별 설명문 + 파라미터 폼). `needsConfirmation` 제약은 노란 "확인 필요" 배지.
- 규칙 복제/저장/가져오기. 저장 전 사전 점검 결과를 우측에 상시 표시.

### 4.6 출제 이력
- 시험 목록(제목, 일시, 과목, 규칙, 시드). 행 클릭 → 당시 확정본 미리보기, "같은 시드로 다시 만들기", "다시 저장".

### 4.7 설정
- 백업 만들기/복원(마지막 백업 시각 표시), 데이터 폴더 위치(읽기 전용 표시 + 폴더 열기), 테마, 업데이트 확인(현재 버전, 변경 내용), 기본 저장 폴더, 글꼴/템플릿.

## 5. 컴포넌트 규칙

- 버튼: 주(accent 채움) 화면당 1개 / 보조(윤곽선) / 위험(danger). 높이 32, 비활성은 이유를 툴팁으로.
- 입력: 라벨 위, 오류 문구는 입력 아래 `--danger` + 아이콘.
- 표: 헤더 고정, 행 높이 36(촘촘) / 56(미리보기 포함), 줄무늬 없이 구분선, 호버/선택 배경 `--accent-soft`.
- 배지: 경고/오류/확인 필요/등급. 텍스트 + 아이콘.
- 토스트: 우하단, 실행 취소 버튼 포함, 5초.
- 대화상자: 포커스 가둠, Esc 닫기, 위험 동작은 영향 범위 문구 포함.
- 로딩: 1초 넘는 작업은 진행률/단계 문구. 스켈레톤은 목록만.
- 접근성: 모든 아이콘 버튼에 `aria-label`, 포커스 순서 = 시각 순서, 대비 AA.

## 6. 검수 방법 (Claude)

UI 단계가 끝나면 앱을 실행해 각 화면 스크린샷을 찍어 이 문서와 대조한다. 확인 항목: 토큰 준수, 빈/오류/로딩 상태 존재, 키보드 이동, 최소 창 크기에서 깨짐 없음, 다크 모드, 긴 한국어 문장 줄바꿈, 문제 800개 규모 목록 성능.

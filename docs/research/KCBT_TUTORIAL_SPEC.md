# 국시원 KCBT 튜토리얼 조사 기록 (형식·구성·레이아웃·UI)

> **목적:** 국시원이 공개한 CBT 체험(튜토리얼)의 화면 구성과 흐름을 기록해 두고, 나중에 문제은행(치위생과·간호보건 모의고사)을 국시원 기준에 맞추거나 CBT 형 연습 모드를 만들 때 참고한다.
> **성격:** 문제 내용이 아니라 **형식·구성·레이아웃·UI** 를 우리말로 정리한 명세다. 스크린샷은 저작권 때문에 저장소에 넣지 않고 로컬 `.tmp-realcheck/cbt-research/` 에만 둔다(색인: 그 폴더의 README.md).
> **조사일:** 2026-11-04 / **방법:** 헤드리스 Edge 로 튜토리얼을 끝까지 직접 진행(1600×900), 화면별 스크린샷과 요소 좌표·글꼴·색 추출.

## 1. 개요·출처·한계

- 출처: 국시원 시험안내 > CBT 체험하기 안내 페이지(https://www.kuksiwon.or.kr/ss/cnt/c_8016/view.do?seq=9) 와 그 안의 튜토리얼 본체(https://www.kuksiwon.or.kr/CBT_SS/index.html#/).
- 이 튜토리얼은 **상시·기간제 시험(요양보호사, 간호조무사)용** 이다. 두 직종은 같은 프로그램에 제목·시간표·예시문항만 다르다. **치과위생사 필기는 현재 종이(OMR) 시험이고 CBT 시행 직종 표에 없다**(별도 조사 결과). 따라서 이 명세는 "국시원 CBT 응시자 프로그램의 모양과 기능" 참고용이지 치과위생사 시험 화면 그 자체가 아니다.
- 콘텐츠(디자인·예시문항 등)의 저작권은 국시원에 있고 무단 복제·도용이 금지된다고 튜토리얼 첫 화면에 명시되어 있다. **우리는 기능·흐름·정보 구성을 참고하고, 국시원의 로고·캐릭터·예시문항·시각 디자인을 그대로 쓰지 않는다.**
- 한계: 튜토리얼은 로그인·시험 전 과정을 흉내 내는 체험 서비스라 실제 시험 서버 동작(자동 제출, 네트워크 오류 처리 등)은 알 수 없다. 10분 전 알림은 튜토리얼 제한 시간(5분 30초)이 짧아 보지 못했다(5분 전 알림만 확인). 계산기의 계산 결과는 화면으로 검증하지 못했다.

```
        ↓
[로그인: 응시자 신분확인]
   · 안내 대화상자 → 확인

   4 시간표(예시)(6/7)
   5 교시대기(7/7) ─ [교시 시작]
        ↓
[본시험(문제풀이) 화면: 5문항, 제한 5분 30초]
   · 문제 풀이 / 체크 / 메모 / 계산기 / 문제 보기 / 답안 제출
   · 남은 5분 → '시험 종료 알림' 팝업
        ↓ [답안 제출]
[안 푼 문제 경고(있을 때)] → [답안 표기란 확인 화면] → [교시 종료 대기(제출 완료 안내, 다시 풀기 가능)]
        ↓ 시간 종료
[답안카드 확인(30초 후 자동 종료, '본인이 작성한 답안임을 확인' 체크 + 확인)]
        ↓
[시험 종료: 퇴실 안내 · 문제 무단 복제/배포 금지 문구 · 처음으로 / 튜토리얼 종료]
```

- 모든 안내 화면에는 **안내 캐릭터가 말풍선(대화상자)으로 그 화면의 역할을 설명**하고 [확인]을 눌러야 조작할 수 있다. 상단 오른쪽의 빨간 [튜토리얼 안내 종료] 버튼은 안내 단계에서만 보이고 체험을 중단한다.

### 3-4. 안내 단계(7쪽)

- **시험안내**: 위쪽에 3개 진행점(유의사항 · 부정행위 · 비밀유지)을 선으로 잇고 현재 점을 채움. 아래 본문 박스(테두리 #bcc9dd)에 불릿(▶) 문단. 쪽마다 [이전]/[다음]. 유의사항(시간 안내방송 없음, 신분증 지참, 시행본부·감독관 지시 준수, 통신·전자기기 소지 시 부정행위 처리), 부정행위(대리시험, 대화·신호, 타인 모니터 보기 등 항목), 비밀유지(문제 유출·게재·출판 금지, 위반 시 민·형사 책임) — 문구 요지만 기록.
- **사용법**: 위에 **탭 3개**(상단메뉴 / 문제풀이 / 하단메뉴: 폭 317, 높이 46, 모서리 12px, 선택 탭은 #0070c9 배경 흰 글자, 나머지 #f8fafb). 내용 영역 960폭, 배경 #edf1f6. 항목마다 **왼쪽 설명용 작은 이미지(260폭, 어두운 남색 배경에 해당 UI 확대)** + 오른쪽 `● 제목`과 `- 설명` 문장.
  - 상단메뉴 항목: 좌석번호(원형 표시) · 응시자 정보(누르면 상세 팝업) · 글자크기(80/100/125%) · 화면배치(1단/2단 보기) · 제한시간/남은시간.
  - 문제풀이 항목: 답 선택/변경(선택하면 선택 번호와 답안 표기란에 마킹, 다른 선지를 누르면 이전 선택이 취소) · 정답 제외/취소(선지 오른쪽 [오답]을 누르면 취소선, [해제]로 복구) · 체크문제 제외/취소(체크 아이콘 토글, 체크 문제 목록에 저장) · 메모 저장/삭제(메모장 노출, 작성하면 아이콘 변경, [내용 삭제]).
  - 하단메뉴 항목: 페이지 이동(이전/다음, 예: `28/64`) · 계산기 사용(하단에 계산기 노출).
- **예제풀이**: 가운데 카드에 큰 안내 문구 + 짙은 남색 알약 버튼 [문항예제 연습하러 가기](폭 380). 연습을 마치고 돌아오면 "예제풀이가 완료되신 분은 다음으로 넘어가시기 바랍니다"(빨강)가 추가됨.
- **시간표(예시)**: 표 1개(구분 / 시험과목(문제수) / 시험형식 / 입장시간 / 시험시간). 간호조무사: 오전·오후 각각 과목 4개(문항수 표기), 시험형식 `객관식`, 입장 `~09:40`, 시험시간 `10:00~11:45 (105분)`. 요양보호사: 열이 더 많음(입장시작/입장완료/시험시작/시험시간/중도퇴실 가능시간), 90분. 표 아래에 "튜토리얼 문제는 이해를 돕기 위한 예시문제" 문구.
- **교시대기**: 큰 문구 "교시 시작 버튼을 클릭하면 시험이 시작됩니다", 파랑 안내 + 빨강 경고("PC 임의조작 시 부정행위 처리"), 정보 표(시험명·교시·시작 시간·종료 시간), 빨간 [교시 시작] 버튼. 실제 시험에서는 카운트다운 후 자동 시작된다는 안내가 대화상자에 있음.

  - **줄기와 선지는 이미지(캔버스)로 그려져 있어 선택·복사가 안 된다.** 글자 크기 변경에 따라 이미지가 다시 그려진다.
  - **보기 상자**: 줄기 아래 테두리 상자 안에 불릿(·) 문장들. **그림 문항**: 줄기 아래 이미지 + 가운데 `[ 그림 1 ]` 캡션(굵은 `(그림 1)` 표기는 줄기 안에도 나옴).
  - **선지**: ①~⑤ 를 **동그라미 숫자**로 표기, 번호와 내용 사이 간격 좁음, 한 줄당 약 41px 간격. 선지 행 오른쪽 끝에 작은 **[오답] 버튼**(34×23, 11px, 테두리 #ccd0d5, 배경 #f8fafb). 선택된 선지는 **번호 원이 검은 원으로 채워짐**(●).
  - **형광펜**: 줄기 오른쪽에 작은 버튼 2개(34×26, 8px 글자) — `형광펜 꺼짐/켜짐`(켜지면 연두 #b6e61a 계열 바탕) 과 `형광펜 지우기`. 켠 뒤 줄기를 드래그하면 글자 뒤에 연한 노랑-연두 띠가 칠해지고, 지우기로 모두 지움(문항별 상태).
- **답안 표기란(우측 고정 열)**: 폭 250, 헤더 "답안 표기란"(배경 #385786, 24px 흰 글자, 높이 46). 문항마다 한 줄(높이 40): 왼쪽 번호 칸(30폭, 배경 #d7e1f1, 글자 #5083d4, 굵게) + ①~⑤ 원 버튼(파랑 테두리 원, 글자 #5083d4). 선택된 번호는 **옅은 파랑으로 채워진 원**. **체크문제로 표시한 문항은 번호 칸 왼쪽에 분홍 ✓ 표시**. 이 열의 번호를 눌러도 해당 문항으로 이동/표기가 되는지는 확인하지 못함.
- **하단바 버튼**(모두 높이 34, 흰 배경, 모서리 4px, 아이콘+굵은 글자): 왼쪽 [계산기], 가운데 [이전] `N/M` [다음](첫 쪽엔 이전 없음, 끝 쪽엔 다음 없음), 오른쪽 [전체 문제 (N)] [체크 문제 (N)] [안푼 문제 (N)] 과 마지막 강조 버튼([답안 제출] 또는 [연습 종료]). 괄호 숫자는 실시간 개수.
- **1단/2단 보기**: 2단에서는 문제 영역이 좌우 두 칸(구분 세로선)으로 나뉘고 **각 칸이 자기 문항의 [체크문제][메모][형광펜][오답] 도구를 따로 가짐**. 페이지 표기는 `1/2`처럼 **두 문항 단위 쪽수**. 글자 125%에서도 2단 유지(긴 선지는 아래로 넘침).

### 7-2. 제안(우선순위)
1. **시험지 머리 정보 표준화**: 교시, 과목 구성(문항 수), 시험 시간(교시당 85분 등), 1문항 1점·총점, 문항 번호 구간을 시험지 맨 위에 표시하고 규칙 프리셋에 저장. (실제 시험: 1교시 의료관계법규 20 + 치위생학1 80=100문항 85분, 2교시 100문항 85분 — 별도 조사 참고)
2. **홀수형/짝수형 동시 생성**: 같은 문제 집합에서 문제 순서·선지 순서를 달리한 두 유형을 한 번에 만들고 정답지를 각각 출력. 이미 있는 shuffler 로 가능. (정확한 두 유형의 차이는 공식 안내 미확인 — 국시원 확인 필요)
3. **OMR 답안카드 출력**: §3-6·3-7 의 "답안 표기란" 구조(번호 + ①~⑤ 원)를 종이용으로 만든 PDF. 홀수형/짝수형 표기 칸 포함.
4. **CBT 형 연습 모드(선택, 장기)**: 위 3-6 의 구성(상단바 / 문제 영역 / 우측 답안 표기란 / 하단 도구바)과 기능 명세표(§4)를 기능 요건으로 삼아, 확정본(ExamSnapshot)을 입력으로 받는 별도 화면(새 screen 플러그인)으로 구현. 기록 항목: 답안·체크·메모·형광펜·소거·남은 시간, 종료 시 채점(정답지와 대조)·과목별 40%/총점 60% 판정. 문제 이미지화(복사 방지)는 우리 저작물 보호용으로 선택.
5. **정답 위치·해설 등 기존 불변 조건 유지**: 어떤 새 기능도 문항별 본문·예문·선지·정답·해설 묶음이 섞이지 않는다는 원칙(ExamSnapshot 불변성)을 지킨다.

### 7-3. 구현 시 주의(저작권·오인 방지)
- 국시원 로고·"KCBT"·캐릭터·튜토리얼 이미지·예시문항·색 조합을 **그대로 쓰지 않는다**. 우리 디자인 시스템(tokens.css)으로 독자 UI 를 만들고, "국시원 공식"으로 오인될 표현을 쓰지 않는다. 국시원 기출·예시문항을 문제은행에 넣지 않는다.
- 이 문서는 형식·기능 요건 참고용이다. 구현할 때는 기능 명세(§4)만 따르고 화면은 새로 설계한다.

## 8. 확인하지 못한 것

- 종료 10분 전 알림(튜토리얼 제한시간이 짧아 5분 전만 확인), 안 푼 문제가 없을 때의 제출 확인 문구, 답안 표기란 번호를 눌렀을 때의 동작, 계산기 계산 결과, [PC설정] 버튼의 내용, 정답 제외 시 취소선의 정확한 시각 효과(버튼 변화는 확인).
- 줄기·선지가 이미지인 이유는 복사 방지로 보이나 공식 설명은 없음(추정).
- 치과위생사 시험이 CBT 로 전환될 때의 화면이 이 튜토리얼과 같을지는 알 수 없음. 'CBT 종합안내서'(2026-08-24 공지 PDF)에 화면 설명이 있을 수 있으나 열지 못함.
- 국시원 CBT 응시자 프로그램의 네트워크·장애 대응, 감독관 화면, 실제 시험의 자동 시작 카운트다운 화면.

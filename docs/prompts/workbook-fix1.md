# 작업: workbook 모듈 보정 1 (문제집 번호 인식 개선)

먼저 `AGENTS.md` 를 읽고 따른다. git commit/push 는 하지 않는다. `src/contracts/index.ts` 수정 금지. 실제 문제 파일(`문제 디비/`, *.pdf, *.docx)은 읽지 않는다(테스트는 가짜 문서만).
대상: `src/modules/workbook/` (`question-book.ts` 중심, 필요하면 `answer-book.ts`, `build.ts`) 와 테스트, `tests/fixtures/workbook.ts`.

## 실제 책으로 확인한 문제 (실제 문서를 직접 돌려 본 결과)
1. **선지가 그림 안에 있는 문제**: 번호 줄(`034`) 다음에 문제 본문(`… 그림이다. …`)만 있고 `①`~`⑤` 줄이 **글자로 없다**(선지가 그림 이미지 안에 있음). 지금 규칙(번호 뒤 12줄 안에 `①` 필수)에 걸려 문제로 인식되지 않고, 그 뒤 번호가 "기대 번호와 다르다"며 **그 과목의 나머지 문제를 모두 불확실로 버린다**(한 과목이 33문제만 남음). 이게 가장 큰 문제다.
2. **표가 들어 있는 문제**: 번호 줄 다음에 표 내용이 한 줄에 한 칸씩 20줄 이상 나오고 그 뒤에야 `①` 이 나온다. 12줄 규칙에 걸린다.
3. **긴 선지**: 법 조문 같은 긴 선지는 5줄 이상 이어진다. 지금 "이어지는 줄 4줄 초과 → WORKBOOK_CHOICES_BROKEN 오류"로 멀쩡한 문제가 버려진다.
4. 정답집에서 한 항목의 `◆` 학습목표 접두가 속한 과목(번호 초기화 순서로 정한 과목)과 다르면 지금은 `WORKBOOK_PART_MISMATCH` 로 **그 항목을 통째로 제외**한다. 책의 오타일 수 있으므로 항목은 살리고 학습목표만 비운다.

## 고칠 내용
### A. 문제 시작 판정 (`question-book.ts`)
- 한 과목 안에서 `^\d{3}$` 줄이 **기대하는 다음 번호**와 같으면 **그 자체로 문제 시작**이다. 뒤에 `①` 이 있는지는 보지 않는다.
- 기대 번호보다 큰 `^\d{3}$` 줄(`기대+1 ~ 기대+5`)은 **그 뒤 40줄 안에 `①` 줄이 있을 때만** 문제 시작으로 받아들인다(번호가 빠진 책 오타 대비). 이때 `WORKBOOK_NUMBER_GAP` (warn) `○○ N번~M번이 문제집에 없습니다` 를 **한 번만**(빠진 구간 하나당 하나) 낸다. 건너뛴 번호는 문제집에 없는 것으로 둔다.
- 기대 번호보다 작거나 같은 줄, 또는 그 밖의 숫자 줄은 문제 시작이 아니고 그냥 본문 줄(요약쪽 숫자 등)이다. **번호가 어긋났다고 뒤 문제를 버리지 않는다.** (지금의 "이후 불확실한 문제는 제외합니다" 동작을 없앤다.)
- 문제 본문(stem)은 번호 줄 다음부터 첫 `①`(선지 시작) 전까지다. 시작 규칙과 같이, 문제 끝은 다음 문제 시작/`KILLER POINT`/`출제 연도 기출 내용`/`제 N 장`/`PART`/잡음 줄이다.

### B. 선지가 없는 문제 (그림 속 선지)
- 본문은 있는데 글자로 된 선지가 하나도 없으면 `SKIPPED_NO_TEXT_CHOICES` (warn) `○○ N번: 선지가 그림 안에 있어 글자로 읽지 못했습니다. 그림 문제는 이 가져오기로는 넣을 수 없으니 문제 추가에서 직접 입력하세요.` 로 **제외**한다(`SKIPPED_` 접두 진단은 다른 importer 와 같은 모양으로, 앱이 "저장하지 않은 문제와 사유"에 보여 준다).
- 선지가 1개뿐이거나 번호 순서가 어긋나면 지금처럼 `WORKBOOK_CHOICES_BROKEN` error (그 문제만 제외, 과목의 나머지는 계속).

### C. 표/그림 문제 표시
- 본문 줄(번호~첫 선지)이 **8줄을 넘으면** 표나 그림 글자가 섞인 문제로 보고 `WORKBOOK_FIGURE_MISSING` (warn, 기존과 같은 문구)을 낸다. 이런 문제의 본문 줄은 **줄 이음을 하지 말고 줄마다 문단으로** 둔다(표 칸을 한 줄로 이어붙이지 않기 위해). 8줄 이하는 지금처럼.
- 기존 `그림`·`표를`·`아래 표`·`다음 표`·`도표` 키워드 경고는 유지.

### D. 선지 이어붙는 줄 상한
- 마지막 선지가 아니어도, **선지에 이어 붙는 줄 상한을 4 → 12 로** 올린다. 요약쪽 침범은 종료 조건(위)으로 막는다. 12줄을 넘으면 그 문제만 `WORKBOOK_CHOICES_BROKEN`.

### E. 정답집 접두 불일치
- 항목은 번호 초기화 순서로 정한 과목에 **그대로 둔다**. 그 항목의 `◆ 접두` 가 그 과목 접두와 다르면 `objectiveCode` 를 **비우고** `WORKBOOK_PART_MISMATCH` (warn, 번호 포함: `○○ N번: 학습목표(◆ 병리 …)가 과목과 달라 비웠습니다`) 를 낸다. (과목 구간의 다수결 접두가 카탈로그 접두와 다르면 지금처럼 구간 전체를 경고하고 접두가 가리키는 과목을 우선하는 동작은 유지.)

## 테스트 추가 (가짜 문서)
- 선지 없는 그림 문제가 중간에 끼어 있어도 뒤 문제들이 모두 인식됨(개수·번호 대조), 그림 문제는 `SKIPPED_NO_TEXT_CHOICES`.
- 표 글자 20줄 뒤에 선지가 오는 문제가 인식되고 `WORKBOOK_FIGURE_MISSING`, 본문이 줄마다 문단.
- 6줄 이상 이어지는 긴 선지가 정상 인식, 13줄은 오류.
- 번호가 하나 빠진 책: 앞뒤 문제가 모두 살고 `WORKBOOK_NUMBER_GAP` 이 한 번만.
- 요약쪽(`KILLER POINT`)의 숫자 줄(`2025` 같은 4자리, `100` 같은 3자리가 기대 번호와 다르면)이 문제로 오인되지 않음. **기대 번호와 같은 3자리 숫자가 요약쪽 안에 있는 경우**는 문제 시작으로 오인될 수 있으므로, `KILLER POINT` 줄을 만나면 **다음 `^\d{3}$` + 40줄 안 `①` 이 있는 줄까지는** 문제 시작을 찾지 않는다(기존 요약쪽 건너뛰기 규칙 유지·테스트).
- 정답집 접두 불일치 항목은 살아 있고 학습목표만 비어 `SKIPPED_NO_OBJECTIVE`(기본 옵션) 또는 `requireObjective:false` 면 포함.
- 기존 테스트 전부 통과(변경된 동작에 맞게만 수정).
